# 医学复习讲义生成器

将课程 PPT/PDF 转化为逐页锚定、在可靠提取范围内尽可能替代原课件的期末冲刺讲义。无法可靠识别的课件图像必须保留原图或截图锚点，不得猜测。内置基础医学和临床医学两套独立提示词体系，按学科特征自动判定并匹配最佳模板。

## 触发模式

用户可在请求中声明模式（优先级从高到低）：

- `临床` / `基础` → 强制走对应模式
- `混合` / `对照` → 强制混合模式，同时生成两套讲义+对照表
- 未声明 → **默认 AI 自动判断**（基于关键词评分）

## 工作流水线

1. **接收材料**：识别用户上传的 `.pptx`/`.pdf` 文件
2. **学科判定**：提取 PPT 文本内容，按关键词评分判定学科类型（见 §学科判定算法）
3. **存量检测**：扫描 `复习/` 目录，若已存在对应学科的另一种讲义，自动追问是否生成/更新对照表
4. **读取模板**：根据判定结果读取 `references/clinical.md` 或/和 `references/basic.md`
5. **生成讲义**：严格按参考文件中的模板规则生成完整讲义
6. **保存输出**：写入 `复习/{科目}/`（路径规则见 §输出规则）
7. **格式标准化**：**必须执行**——对每个生成的 .md 文件运行 personal-format 脚本（见 §格式强制流程）
8. **格式验证**：**必须执行**——读取格式化后的文件，逐条核验 §格式验证清单
9. **复习建议**：末尾给出学科个性化复习建议（见 §复习建议映射）

## 学科判定算法

### 临床特征词（命中 +1 临床分）

诊断标准、鉴别诊断、金标准、首选检查、治疗方案、治疗原则、药物治疗、
手术指征、术式选择、临床表现、症状、体征、并发症、预后、随访、临床分期、
鉴别诊断、首选药物、禁忌症、适应症

### 基础特征词（命中 +1 基础分）

镜下、染色、切片、光镜、电镜、解剖位置、毗邻、层次、体表投影、代谢通路、
限速酶、糖酵解、三羧酸循环、动作电位、离子通道、膜电位、胚胎、胚层、发育来源、
代偿机制、失代偿、级联放大、药代动力学、生物利用度、首过效应、信号转导、
大体形态、分部、血管供应、神经支配、组织分布、细胞类型、镜下结构、发育来源

### 判定逻辑

- `基础分 - 临床分 ≥ 2` → 基础医学模式
- `临床分 - 基础分 ≥ 2` → 临床医学模式
- `|基础分 - 临床分| ≤ 1` → 混合模式
- 若基础分与临床分均为 0（未命中任何特征词）→ 暂停生成并提示用户手动声明学科类型

判定结果须在解析摘要中声明："经自动判定：基础分 X vs 临床分 Y，采用 [基础/临床/混合] 模式"。

## 纯基础模式

读取 `references/basic.md`，按以下步骤执行：

1. 根据课件内容特征选择六模板之一（A 大体解剖 / B 组织胚胎 / C 生理学 / D 病理生理 / E 药理学 / F 生物化学）
2. 按模板要求生成讲义
3. 输出到 `复习/{基础科目}/`

若复习目录中已存在对应疾病的临床讲义，自动追问："检测到复习/{临床科目}/ 中已有相关临床讲义，是否需要同步生成/更新基础-临床对照表？"

## 纯临床模式

读取 `references/clinical.md`，按以下步骤执行：

1. 根据课件内容选择三模板之一（模板1 完整疾病单元 / 模板2 鉴别诊断 / 模板3 急症处理）
2. 按模板要求生成讲义
3. 输出到 `复习/{临床科目}/`

若复习目录中已存在对应机制的基础讲义，自动追问："检测到复习/{基础科目}/ 中已有相关基础讲义，是否需要同步生成/更新基础-临床对照表？"

## 混合模式

同时读取 `references/basic.md` 和 `references/clinical.md`，产出三份文件：

1. **基础讲义**：用基础模板整理基础机制部分 → `复习/{科目}/{主题}_基础讲义.md`
2. **临床讲义**：用临床模板整理临床疾病部分 → `复习/{科目}/{主题}_临床讲义.md`
3. **基础-临床对照表** → `复习/{科目}/{主题}_对照表.md`

对照表模板：

| 基础知识点 | 基础概念（一句话） | 对应临床疾病 | 临床关联机制 | 优先级 |
|-----------|-----------------|-------------|-------------|--------|
| {{知识点}}（复习/{{基础科目}}/{{文件名}}） | {{一句话}} | {{疾病}}（复习/{{临床科目}}/{{文件名}}） | {{从机制到临床表现的推导}} | ⭐⭐⭐ |

对照表优先级规则：
- ⭐⭐⭐：该基础机制直接决定临床治疗方案
- ⭐⭐：该基础机制用于理解临床表现，不直接决定治疗
- ⭐：背景知识，了解即可

## 存量检测

生成前须扫描 `复习/` 目录：

- 检查是否存在同科目的讲义文件（按文件名关键词匹配）
- 若当前为纯基础模式且发现对应临床讲义 → 自动追问对照表
- 若当前为纯临床模式且发现对应基础讲义 → 同样追问
- 若用户已明确拒绝对照表生成，不再重复询问

## 输出规则

### 目录

- 所有输出写入 `复习/{科目}/`
- `{科目}` 由 AI 根据课件内容判定（如"解剖学""生理学""内科学""实验诊断学"）
- 用户声明科目时以用户声明为准
- 目录不存在时自动创建

### 命名

- 纯模式：`复习/{科目}/{主题}_讲义.md`
- 混合基础：`复习/{科目}/{主题}_基础讲义.md`
- 混合临床：`复习/{科目}/{主题}_临床讲义.md`
- 对照表：`复习/{科目}/{主题}_对照表.md`

### 来源边界与图像处理

讲义中的信息必须明确区分以下来源：

- `📎 课件原文：`课件正文、标题、图注或可直接提取的标签
- `🖼 课件图像解读：`从清晰图像中能够可靠识别的标签、图注、结构关系或流程关系；只作客观转写
- `📖 教材解释：`仅用于解释课件已经出现的术语、机制步骤或前置概念
- `⚠️ 图像未可靠识别：`图像模糊、标签缺失或结构无法确认时，保留原图/截图锚点并明确提示需结合原图

按以下顺序处理课件图片：

1. 可明确识别标签、图注或结构关系时，客观转写并标记 `🖼 课件图像解读：`。
2. 无法可靠识别时，不描述、不猜测、不用教材内容代替原图；保留原图或截图锚点并标记 `⚠️ 图像未可靠识别：需结合原课件第 X 页图像复习`。
3. 教材只能解释已经确认出现在课件中的实体或机制，不得冒充课件图像的原始信息。

教材解释允许补足已有术语的定义、已有机制步骤的因果联系及必要前置概念；禁止新增课件未出现的疾病、解剖结构、分类、诊断阈值、药物选择、治疗方案、预后数据和考试结论。若课件只出现主题名称而没有足够内容，必须声明信息缺口，不得用教材扩写成完整知识单元。

### 折叠式自测规则

- 允许在每个知识单元末尾生成少量折叠式自测，用于主动回忆，不建立独立题库。
- 每道自测使用 `> [!QUESTION]- 参考思路`，参考思路只能复述或推导本讲义已经覆盖的内容。
- 不使用选择题、填空题、名词解释、简答题等正式考试题型，不引入课件外考点。

### 格式强制流程

**每份讲义写入后，必须按以下两步执行，不可跳过：**

**Step 1 — 运行 personal-format 脚本**：

```bash
python "C:\Users\29731\.Codex\skills\personal-format\scripts\personal_format.py" "复习/{科目}/{文件名}.md"
```

该脚本自动处理：`---`→`***`（除 YAML frontmatter）、去概述 H1、清空行、表格/Callout 间距修复、`\n`→真实换行。

**Step 2 — 验证清单**：脚本运行后，用 `Read` 工具重新打开文件，逐条核验：

- [ ] **零空行**：正文段落间无空行。仅表格前后保留空行、Callout 块间保留空行。Callout 内部和 mermaid 代码块内无多余空行
- [ ] **分隔符**：正文中不存在 `---`，所有分隔线均为 `***`
- [ ] **H1 顶级**：第一个 `#` 标题与文件名不重复。全文最高层级为 `#`，无降级
- [ ] **表格渲染**：每个表格前有且仅有一行空行、表格后紧接下一行（若后接 Callout 则保留 Callout 空行）
- [ ] **Callout 渲染**：`[!NOTE]`/`[!WARNING]`/`[!SUMMARY]`/`[!TIP]`/`[!QUESTION]` 标记完整且未被破坏
- [ ] **mermaid 完整**：所有 mermaid 代码块首尾 ` ``` ` 完整，未被脚本误修改
- [ ] **无残留 `\n`**：文本中无 `\\n` 字面量残留

**发现不符合项时**：手动修复后重新运行脚本，再次验证。最多迭代 2 轮，第 2 轮仍不通过则报告具体问题并标注 `⚠️ 格式验证未完全通过`。

## 复习建议映射

| 检测到学科 | 复习建议 |
|----------|---------|
| 大体解剖学 | 建议配合解剖图谱（Netter/人卫系统解剖图谱）+ 体表触诊定位，用自身身体作为参照系记忆位置毗邻关系。每学完一个区域，在自身上指出对应体表标志和深层结构投影。 |
| 组织胚胎学 | 建议以图片记忆为主：多看典型切片图，记住"这张染色下这个细胞长什么样"。推荐使用虚拟切片库练习镜下辨识。用"分层→细胞→功能"三要素卡片做闪卡训练。 |
| 生理学 | 建议用"推导笔记法"：不看讲义，从机制起点的刺激或条件开始，一步一步推导到终点效应。能独立推导三遍即掌握。关键曲线（如氧解离曲线）建议手绘并标注拐点意义。 |
| 病理生理学 | 建议对照临床案例学习：为每个病理过程找一个对应的临床疾病，从病因→始动环节→级联放大→代偿与失代偿→临床表现完整推演。理解"为什么出现这个症状"比死记重要百倍。 |
| 药理学 | 建议制作自己的"药物对比表"：按类别横向对比机制、效应强度、不良反应、首选适应症、禁忌。辅以临床案例（如"高血压患者如何选药？"）强化用药逻辑。特别注意同类药物的细微差异——这是考试最爱考的。 |
| 生物化学 | 建议手写代谢通路：反复默画关键步骤、限速酶和调控节点。用不同颜色标记能量消耗/产出、正向调控/反向调控。推荐使用"代谢地图"全局理解通路交叉。重点记忆不可逆步骤和限速酶。 |
| 内科学 | 建议以"诊断树"为核心复习方法：从主诉症状出发，画出鉴别诊断分支→首选检查→确诊金标准→治疗方案分支。推荐对照《贺银成讲义》同步强化执业医师考点。 |
| 外科学 | 建议以"手术指征"为线索串连疾病：记住每种外科疾病的手术时机、术式选择、并发症处理。辅以解剖学回顾（手术入路涉及的解剖结构）。急症部分按时间窗记忆。 |
| 妇产科学 | 建议分双线复习：产科以孕周时间为轴（孕早期/中期/晚期/分娩/产褥），妇科以症状→诊断→治疗为轴。重点记忆关键时间窗和数值。 |
| 儿科学 | 建议以"年龄差异"为核心：相同疾病在不同年龄段的表现、用药剂量、评估标准均不同。用生长曲线和发育里程碑作为记忆锚点。特别注意新生儿期的特殊生理参数。 |
| 急诊医学 | 建议按"时间窗+ABCDE评估"框架复习：每种急症的识别→评估→处理时间线。可以自制"急诊处理卡片"，正面症状+反面时间窗处理步骤。 |
| 混合学科（基础+临床桥梁） | 本课程为基础-临床桥梁学科。建议先复习基础机制部分（理解"为什么"），再转向临床诊断部分（掌握"怎么用"）。对照基础-临床对照表逐条验证：能否从机制推导出临床表现和治疗逻辑？ |

## 关键约束（综合两套提示词）

- 不新增课件未出现的疾病、结构、分类、诊断阈值、药物选择、治疗方案、预后数据或考试结论
- 禁止独立题库、模拟试题及课件外考点；允许按 §折叠式自测规则生成少量自测
- 对课件图片只作可靠、客观的转写；无法确认时保留原图或截图锚点并声明信息缺口
- 教材解释只解释课件已经出现的实体或机制，不得冒充课件原始内容
- 不使用绝对化表述
- 生成过程中不询问用户
- 输出纯 Markdown，不包含 HTML
